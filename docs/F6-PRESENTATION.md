## 固定入口与数据流

原神 direct-DLSS 路线固定为 **真实源帧呈现输入 → NR → 细节保留 → FG**。

- 实际 Evaluate 只采集当次源身份及 guides，SR Execute 和 CopyBackOutput 成功后才发布 CPU 源准入。旧 placement INI 不再启用原神的 SR 前／后 NR writer。
- 呈现端验证当前 capture、生产队列交接和 FG 所选不可变源描述。每个源事务最多录制一次；生成输出和重复 Present 不再执行 NR。
- 当前原图先复制到独立工作纹理；模型、Look、细节处理均使用私有结果。成功后仅有一处最终发布；准备、失败或无匹配 guides 时保留本帧原图。
- 新原神入口不调用旧呈现光流、间隔成品复用或额外的 native overwrite。模型多层处理继续使用不可变 base、答案 ping-pong 和一次最终合成，保留既有 ratio/HDR 语义。
- 历史携带原始模型残差 anchor、原始输入／深度及真实年龄；显示融合结果不存回历史。当前运动、区域、缩放、深度及原始结构共同约束回投，失败处重新播种。源切场景即失效，不受可选模型重置开关豁免。
- 源连续性包含 feature/context/代次以及呈现 owner/queue；合法输出纹理轮转不造成无谓重置。热重建通过现有真实 queue/fence/Reset 退休，不依赖切窗。
- 原神菜单显示固定路线；保留分辨率、层数、Look、历史时长、NR/FG 方向及 FG 倍率配置。本轮不改任何正式 INI。持续保留仍需用户启用现有总开关和持续保留选项。

源事务和观察状态只负责关联、准入及否决，均不能证明 GPU 完成或允许资源退休。输入预览继续复用已有 GPU 单选条，本轮未增加诊断画布或校准向导。

保留外部桥 2.4.0.0 的启动兼容修复：两类 swapchain 包装器通过 `wrapped/SwapchainHookBoundary.h` 共用七个 final DXGI 控制／颜色入口，再由不可变对象回调表分派。40 项跨布局测试和本次候选的实际二进制入口检查通过；不据此扩大为 HDR 全面兼容。
